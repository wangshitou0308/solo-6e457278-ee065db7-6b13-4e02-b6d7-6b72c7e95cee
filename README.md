# 字幕节奏校准台

本地运行的字幕时间轴校准工具。后端仅使用 Python 标准库（`http.server` + `sqlite3`），
前端为原生 HTML/CSS/JavaScript，**无需账号、密钥或任何外部服务**。

## 启动

```bash
python3 server.py        # 默认端口 8000
python3 server.py 9000   # 指定端口
```

然后浏览器打开 <http://127.0.0.1:8000/>。首次启动自动载入内置示例字幕。

## 功能

- **导入 / 解析**：支持 SRT 与 WebVTT（含 VTT 头部与 cue 设置的保留），自动识别格式。
- **可缩放时间轴**：滚轮缩放（以光标为锚点）、空白处拖动平移、`适配` 按钮或按 `0` 复位；
  红色模拟播放头可播放/暂停（空格），拖动标尺直接定位。
- **本地媒体对照**：载入本地音频/视频（仅通过对象 URL 在浏览器内打开，**不上传、不写数据库**）；
  媒体进度、时间轴播放头、字幕列表高亮与预览文本双向同步——拖动播放头即定位媒体，
  媒体播放时播放头与当前字幕自动跟随。支持播放/暂停、0.5×–2× 倍速，
  以及带前后留白的**单句循环**（反复试听选中字幕区间）。未载入媒体时保留模拟播放头。
- **吸附校时**：选中字幕后，一键（或 `,` / `.`）将起点/终点吸附到当前媒体时间，
  修改同样纳入撤销、重做与本地草稿。
- **双锚点整体校时**：分别记录两条字幕的原时间与媒体正确时间，预览线性偏移 + 伸缩
  对全部字幕的影响，确认后批量应用；锚点冲突、或变换会产生负时间 / 倒序时
  禁止应用并说明原因。
- **拖动校时**：拖动字幕块整体平移，拖动左右边缘调整起止，列表中的时间实时联动。
- **节奏规则检查**：可配置语速上限（字/秒）、最短停留、相邻最小间隔、是否允许重叠；
  问题按类型汇总在右侧面板，点击即可定位到对应字幕。
- **自动顺延**：一键生成保持原有顺序的修复方案（延长过短停留、按间隔向后顺延），
  应用前弹出**修改前后差异预览**。
- **断句拆分**：把光标放在字幕文本中，点行内「拆」或按 `Ctrl+Enter` 即可拆为前后两条。
  播放头位于原时间段内时以播放头为分界，否则按两侧有效字符数（不计 HTML 标签与空白）
  比例分配时长；仅当前后均有文本、且分界时间合法时才允许拆分。未聚焦文本框点「拆」时，
  会沿用点击前的光标位置；没有历史光标时按文本中点回退。
- **相邻合并**：行内「合」将本条与下一条合并，时间覆盖原有区间；SRT 自动重排序号，
  WebVTT 保留第一条的 cue 标识符与设置（拆分新增段不写入自动编号）。
- **分行规则**：可配置每行字数与每条最多行数，自动标出**超长行**、**孤立标点**
  （行首的句末/后引号类标点）与**超出行数**的字幕，并汇入右侧节奏检查面板。
- **智能分行**：行内「排」对单条重排，「批量重排…」先给逐条预览再应用。优先在标点或
  空格处换行，不拆开 HTML 标签、英文单词或数字串；允许句末标点悬挂（仅超宽一个标点），
  绝不制造新的孤立标点，也绝不删字。无法满足限制时明确说明原因（过长的词 / 行数不足）。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），拖拽与连续微调自动合并为一步；
  拆分 / 合并 / 分行等结构操作各自独立成步，且在拆分后新文本框仍聚焦时快捷键同样生效。
- **键盘微调**：`←`/`→` 整体平移；`[` `]` 调起点；`;` `'` 调终点；
  步进 100ms，`Shift` 500ms，`Alt` 10ms；`↑`/`↓` 切换选中行。
- **文本搜索**：`Ctrl+F`，命中行高亮，回车跳转下一个（`Shift+Enter` 上一个）。
- **本地草稿**：每次修改自动保存到后端 sqlite3（`drafts.db`，按文件内容哈希区分）；
  重新导入同一文件时提示恢复，导出后自动清除。
  刷新页面只恢复字幕编辑状态，媒体文件不会保存，会提示重新选择。
- **导出**：保留文本换行与 WebVTT 头部 / cue 设置，可导出为原格式 / SRT / VTT；
  拆分、合并后 SRT 序号按顺序重排，VTT 显式标识符原样保留。

## 目录结构

```
server.py          # 后端：静态文件 + /api/sample + /api/draft（sqlite3）
static/index.html  # 页面结构
static/style.css   # 深色主题样式
static/core.js     # 纯逻辑：解析/序列化/分析/自动顺延/双锚点/拆分/合并/智能分行（浏览器与 Node 通用）
static/app.js      # 界面交互：时间轴、拖拽、撤销重做、搜索、草稿、导出、媒体对照、断句分行
tests/test_core.js # 核心逻辑单元测试（Node）
tests/test_dom.js  # DOM 集成测试（可选，需 jsdom：npm install --no-save jsdom）
tests/e2e.js       # 浏览器端到端测试（可选，需 playwright-core + Chromium）
```

## 测试

```bash
node tests/test_core.js   # 核心逻辑单元测试
node tests/test_dom.js    # DOM 集成测试（未装 jsdom 时自动跳过）
python3 -m py_compile server.py
```

端到端测试（可选）：`npm install playwright-core && npx playwright-core install chromium`
后，启动服务器于 8123 端口，执行 `node tests/e2e.js`。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/sample` | 内置示例字幕 |
| GET | `/api/draft?key=` | 查询草稿 |
| POST | `/api/draft` | 保存草稿 `{key, filename, format, content}` |
| DELETE | `/api/draft?key=` | 删除草稿 |
| GET | `/api/health` | 健康检查 |
